## 1. Какие данные мы собираем

| Данные | Зачем | Обязательно |
| --- | --- | --- |
| E-mail | вход, подтверждение, письма сервиса | да |
| Пароль | вход (хранится только в виде хеша, мы его не знаем) | да |
| Имя и фамилия | приветствие | нет |
| Дата рождения | запрос в Migraciones (нужна для проверки номера) | только для этого сервиса |
| Telegram id и имя пользователя | отправка уведомлений | только для Telegram-уведомлений |
| Номера дел и отправлений, ваши названия к ним | отслеживание | да, это суть сервиса |
| Статусы и этапы дел, полученные с сайтов-источников | показ в кабинете, уведомления | да |
| Записи о платежах (сумма, дата, способ, провайдер) | учёт, чеки, поддержка | при оплате |
| Технические журналы и IP | безопасность, защита от злоупотреблений, разбор ошибок | автоматически |
| Ваши сообщения в поддержку и ответы | помощь | при обращении |

Мы **не** храним номера банковских карт: оплату принимает Mercado Pago. Мы не просим и не храним пароли от сайтов-источников. Мы не продаём данные и не используем их для рекламы третьих лиц.

## 2. Основание и цели

Данные нужны, чтобы оказывать сервис, который вы просите: следить за статусами и присылать уведомления. Необязательные поля вы заполняете по желанию. Согласие даётся при регистрации и может быть отозвано удалением аккаунта. [ЮРИСТ: форма согласия, отдельное согласие на дату рождения.]

## 3. Кому передаём

Для работы сервиса мы пользуемся поставщиками: хостинг [название, страна], отправка почты [название], Telegram (доставка сообщений), Mercado Pago (платежи). Они получают только то, что нужно для их функции. Часть поставщиков может находиться за пределами Аргентины. [ЮРИСТ: условия трансграничной передачи по Ley 25.326, ст. 12.]

## 4. Срок хранения

Данные аккаунта хранятся, пока он существует. При удалении аккаунта мы удаляем отслеживания, статусы, профиль и привязку Telegram. Записи о платежах и журналы, которые мы обязаны хранить по налоговому и коммерческому праву, сохраняются в необходимом объёме и срок [ЮРИСТ/CONTADOR: срок]. Техническое резервное копирование стирается в течение [N] дней.
