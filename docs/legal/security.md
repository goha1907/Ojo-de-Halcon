**Что сделано**

- Пароли хранятся только в виде хеша (scrypt), мы их не знаем и не можем прислать.
- Вход защищён защитой от перебора: ограничения по IP и по аккаунту, временные адреса почты не принимаются.
- Сессии в защищённых cookie (httpOnly), срок жизни ограничен.
- Передача данных по HTTPS [после запуска на домене].
- Данные карты не касаются наших серверов: платежи принимает Mercado Pago.
- Мы не храним пароли от сайтов-источников; для отслеживания достаточно номера.
- Проверки без добавления ограничены: нельзя перебирать чужие номера.
- Действия сотрудников в админке записываются в журнал; права разделены по ролям.
- Секреты хранятся в окружении сервера, не в коде.
- Регулярные резервные копии базы [после запуска].

- Двухфакторный вход для сотрудников.
