# Дизайн-система

Бренд монохромный: графит на светлом, белый на тёмном. Логотип и палитра: варианты 7 (светлая) и 8 (тёмная) утверждённого референса Concept B «The Sentinel». Акцентного цвета нет: кнопки и ключевые элементы цвета бренда.

Токены лежат в `apps/web/src/app/globals.css` (единственный источник). Тема переключается атрибутом `data-theme="dark"` на `<html>`; `dark:` в Tailwind работает от него же. Интерфейс сразу делаем под обе темы: цвета только через токены, никаких `slate-*`, `white`, `#hex` в компонентах.

## Токены

| Утилита | Светлая | Тёмная | Для чего |
|---|---|---|---|
| `bg-bg` | `#FFFFFF` | `#0F172A` | фон страницы |
| `bg-bg-subtle` | `#F8FAFC` | `#1E293B` | вторичный фон, секции |
| `bg-surface` | `#FFFFFF` | `#1E293B` | карточки, панели, поля |
| `border-line` | `#E5E7EB` | `#334155` | границы, разделители |
| `text-fg` | `#111827` | `#F9FAFB` | основной текст |
| `text-fg-muted` | `#6B7280` | `#CBD5E1` | вторичный текст |
| `text-fg-subtle` | `#94A3B8` | `#94A3B8` | только декор и отключённое (на белом 2.6:1) |
| `bg-brand` / `text-brand-fg` | `#1F2937` / `#FFFFFF` | `#FFFFFF` / `#0F172A` | основные кнопки, ключевые элементы |
| `bg-brand-hover` | `#111827` | `#E5E7EB` | наведение на основную кнопку |
| `ring-ring` | `#1F2937` | `#FFFFFF` | фокус с клавиатуры |
| `success` `warning` `error` `info` | `#10B981` `#F59E0B` `#EF4444` `#3B82F6` | `#34D399` `#FBBF24` `#F87171` `#60A5FA` | значки, полосы, индикаторы |
| `*-bg` | `#ECFDF5` `#FFFBEB` `#FEF2F2` `#EFF6FF` | `#064E3B` `#78350F` `#7F1D1D` `#1E3A8A` | фон сообщений |
| `*-fg` | `#047857` `#B45309` `#B91C1C` `#1D4ED8` | `#6EE7B7` `#FCD34D` `#FCA5A5` `#93C5FD` | текст на `*-bg` |

Из палитры референса взяты все значения, кроме `*-fg`, `brand-hover` и `ring`: их я добавил, потому что `success` и т. п. на своём светлом фоне не дают контраста для текста (`#10B981` на `#ECFDF5` около 2.4:1). Контраст пар проверяет `src/lib/design-tokens.test.ts` (текст не ниже 4.5:1, фокус не ниже 3:1, обе темы).
