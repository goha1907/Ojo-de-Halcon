# Дизайн-система

Бренд монохромный: графит на светлом, белый на тёмном. Логотип и палитра: варианты 7 (светлая) и 8 (тёмная) утверждённого референса Concept B «The Sentinel». Акцентного цвета нет: кнопки и ключевые элементы цвета бренда.

**Выбранное направление (2026-10-16):** стиль «Графит», акцент графит, круглые формы, анимации включены, обе темы. Концепты, из которых выбирали, лежали на отдельной странице; остальные варианты (Аврора, Жирный, Журнал, Радар и цветные акценты) не используются.

Токены лежат в `apps/web/src/app/globals.css` (единственный источник). Тема переключается атрибутом `data-theme="dark"` на `<html>`; `dark:` в Tailwind работает от него же. Интерфейс сразу делаем под обе темы: цвета только через токены, никаких `slate-*`, `white`, `#hex` в компонентах.

## Формы и движение

- Скругления через токены: `rounded-card` (24 px: карточки, модалки), `rounded-field` (14 px: поля, плитки), `rounded-btn` (пилюля: кнопки, чипы, переключатели). `rounded-lg/xl/2xl` в новом коде не используем.
- Кнопка-ссылка: `buttonClass({ variant, size })` из `@ojo/ui` вместе с `next/link`.
- Выпадающие списки: только `Select` / `SelectField` из `@ojo/ui` (свой список: стрелки, Home/End, Enter, Esc, поиск по первым буквам, открывается поверх модальных окон и разворачивается вверх у края экрана). Нативный `<select>` не используем: его список нельзя оформить. Для выбора даты в админке остался нативный `<input type="date">`.
- Иконки нарисованы вручную (`packages/ui/src/components/icons.tsx`), эмодзи и стандартные пакеты иконок не используем.
- Движение: появление блоков при прокрутке (`.reveal`), бегущая строка источников, пульс «живой» точки, блик на основной кнопке, вращающийся контур «популярного» тарифа, меняющийся статус в демо-карточке. Всё отключается при `prefers-reduced-motion`. Определения в `globals.css`.
- Орёл на фоне hero и финального блока: `.hawk-mask` (маска из `/brand/logo-icon.svg`, цвет = `currentColor`), привязан к ширине контента, а не окна, поэтому не «плавает».

## Тема оформления

Переключатель «Как в системе / Светлая / Тёмная» (`components/theme/theme-selector.tsx`): шапка лендинга и подвал, страницы входа, меню кабинета. Выбор хранится в cookie `ojo_theme` (нет cookie = как в системе). Сервер ставит `data-theme` на `<html>` для явного выбора, а скрипт в `<head>` (`THEME_INIT_SCRIPT`) выбирает тему по системной до первой отрисовки, чтобы не было вспышки. Логика и скрипт покрыты `src/lib/theme.test.ts`.

## Правила

- **Ссылки** графитовые (`text-fg`) с подчёркиванием, наведение `hover:text-fg-muted`: акцентного цвета нет, подчёркивание отличает ссылку от текста.
- **Наведение и мягкая заливка** (строки, пилюли, активный пункт меню): `hover:bg-line/40`, `bg-line/40`, активный `bg-line/70`. `bg-bg-subtle` для этого не годится: в тёмной теме он совпадает с поверхностью карточки.
- **Основные кнопки** `bg-brand text-brand-fg`; инверсный блок (финальный призыв) `bg-brand text-brand-fg` с кнопкой `bg-brand-fg text-brand`.
- **Статусы**: фон `*-bg`, текст `*-fg`, точки и полосы `success|warning|error|info`; свечение карточек считается из токена через `color-mix`.
- **Мелкий читаемый текст** `text-fg-muted`; `text-fg-subtle` только для декора и отключённого.
- **Белый `bg-white`** допустим только там, где нужен белый независимо от темы (плашка Mercado Pago с тёмным логотипом).
- Логотип сам меняется по теме (`Logo` рисует обе версии, CSS показывает нужную).
