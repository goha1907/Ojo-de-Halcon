# Дизайн-система

Бренд монохромный: графит на светлом, белый на тёмном. Логотип и палитра: варианты 7 (светлая) и 8 (тёмная) утверждённого референса Concept B «The Sentinel». Акцентного цвета нет: кнопки и ключевые элементы цвета бренда.

Токены лежат в `apps/web/src/app/globals.css` (единственный источник). Тема переключается атрибутом `data-theme="dark"` на `<html>`; `dark:` в Tailwind работает от него же. Интерфейс сразу делаем под обе темы: цвета только через токены, никаких `slate-*`, `white`, `#hex` в компонентах.

## Правила

- **Ссылки** графитовые (`text-fg`) с подчёркиванием, наведение `hover:text-fg-muted`: акцентного цвета нет, подчёркивание отличает ссылку от текста.
- **Наведение и мягкая заливка** (строки, пилюли, активный пункт меню): `hover:bg-line/40`, `bg-line/40`, активный `bg-line/70`. `bg-bg-subtle` для этого не годится: в тёмной теме он совпадает с поверхностью карточки.
- **Основные кнопки** `bg-brand text-brand-fg`; инверсный блок (финальный призыв) `bg-brand text-brand-fg` с кнопкой `bg-brand-fg text-brand`.
- **Статусы**: фон `*-bg`, текст `*-fg`, точки и полосы `success|warning|error|info`; свечение карточек считается из токена через `color-mix`.
- **Мелкий читаемый текст** `text-fg-muted`; `text-fg-subtle` только для декора и отключённого.
- **Белый `bg-white`** допустим только там, где нужен белый независимо от темы (плашка Mercado Pago с тёмным логотипом).
- Логотип сам меняется по теме (`Logo` рисует обе версии, CSS показывает нужную).
