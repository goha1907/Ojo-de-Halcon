# Письма

Все письма собираются одним модулем `packages/core/src/mail/`: общая обёртка (`layout.ts`) и тексты по видам (`templates.ts`, функция `renderEmail`). Тексты живут в словарях i18n (`email.*`, ru/es/en), язык письма берётся из `user.locale`.

Вид: тёмная шапка с белым логотипом (`/images/brand/logo-dark.png` по абсолютному адресу из `APP_URL`), белая карточка, одна кнопка, ссылка-запасной вариант, подвал с почтой поддержки. Табличная вёрстка и инлайн-стили, тёмная тема через `prefers-color-scheme`. У каждого письма есть текстовая версия. Любой пользовательский текст экранируется.

| Вид | Когда отправляется | Статус |
| --- | --- | --- |
| `verify` | подтверждение почты | подключено |
| `reset` | сброс пароля | подключено |
| `passwordChanged` | пароль изменён | шаблон готов, отправку подключить |
| `welcome` | после подтверждения почты, про пробный период | шаблон готов |
| `paymentReceipt` | оплата получена | шаблон готов, подключить к оплате |
| `bonusEnding` | бонусные места скоро отключатся | шаблон готов, нужен планировщик в воркере |
| `subscriptionEnding` | подписка скоро закончится | шаблон готов, нужен планировщик в воркере |
| `supportReply` | ответ поддержки на обращение | шаблон готов |

## Отправка: Resend

Провайдер: [Resend](https://resend.com). Адаптер `createResendMailer` (`packages/core/src/mailer.ts`) обращается к их HTTP API, подключается в `createCoreFromEnv` по переменным окружения:

| Переменная | Что это |
| --- | --- |
| `RESEND_API_KEY` | ключ API (Resend → API keys, право «Sending access»); пустой ключ = консольный драйвер, письма только в логе |
| `MAIL_FROM` | отправитель, по умолчанию `Ojo de Halcón <onboarding@resend.dev>` |
| `MAIL_REPLY_TO` | куда отвечать (адрес поддержки), необязательно |

Пока свой домен не подтверждён в Resend (Domains → Add Domain и записи SPF/DKIM у регистратора), работает только `onboarding@resend.dev`, и письма уходят **только на адрес, на который зарегистрирован аккаунт Resend**. Чтобы писать клиентам, нужен подтверждённый домен: тогда `MAIL_FROM` меняем на `Ojo de Halcón <no-reply@ваш-домен>`.

Ошибка отправки не ломает регистрацию и сброс пароля: она пишется в лог (`mail not sent`), пользователь может запросить письмо снова. Журнал отправок и причины отказов смотрите в Resend → Logs.

## Посмотреть письма

`pnpm --filter @ojo/worker emails:preview [папка]` записывает все письма на всех языках как `.html`-файлы (по умолчанию `email-preview/`), их можно открыть в браузере.

## Как добавить письмо

1. Ключи `email.<вид>.{subject,title,intro,…}` во все три словаря.
2. Вид в `EmailKind` и `EMAIL_KINDS` (`templates.ts`), при необходимости страница кнопки в `PAGE`.
3. Тест `emails.test.ts` проверит все языки сам.
